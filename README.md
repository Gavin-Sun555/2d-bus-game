# 2D Bus Simulator & Route Planner

基于 **Go 语言** 与 2D 游戏引擎 **[Ebitengine](https://ebitengine.org/)** 开发的俯视角都市公交驾驶与线路规划游戏。

> 📖 **开发与架构**：[项目架构与设计说明](docs/architecture.md) &nbsp;•&nbsp; 📋 **更新日志**：[版本更新历史](CHANGELOG.md)

---

## 🎮 核心玩法 (Gameplay)

游戏支持在**驾驶模式**与**线路规划模式**之间随时无缝切换：

1. **🚌 驾驶运营 (Drive Mode)**
   - 亲自驾驶大型城市客车，体验逼真的前后轴距、内轮差与转向循迹。
   - 控制油门、脚刹、手刹与挡位（前进 D / 空挡 N / 倒车 R），顺向靠右停入站台港湾。
   - 到站停稳后开门（`E` 键）上下客，运送乘客赚取票价，按时发车驶向下一站。
2. **🗺️ 线路规划 (Plan Mode)**
   - 按 `TAB` 键切入全景鸟瞰视角，鼠标点击全城各站台，自由规划定制公交线路。
   - 智能有向路网算法自动计算合规行车路径，确保无论如何选站，大巴均顺向从右侧进站。
3. **🤖 自动驾驶与狂暴巡航 (AI Autopilot & Berserk Mode)**
   - **标准巡航 (P 键)**：一键全流程托管！AI 自动沿规划路线巡航、红灯自动刹停、遇前车平稳跟车、自动进站对齐上下客。
   - **智能飞站 (F 键)**：当车内无下车乘客且前方站台无人候车（或已有其他车辆停靠）时，支持手动或自动飞站提速。
   - **狂暴模式 (B 键 / Shift+P)**：解除巡航限速，在长直道全速狂飙；多车道干道遇慢车自动提前变道超车，绿灯直行自适应选择通畅车道。支持按 `Shift+B` 在 60 / 80 / 100 / 120 km/h 间切换最高限速。

## 🌟 游戏特色 (Features)

- **🏙️ 四座大型城市与自定义地图**：
  - `01 都会核心`：公交专用八车道主干路为主，搭配六车道与四车道道路、运河景观。
  - `02 海滨港湾`：黄金海岸公路、高密度港口与跨海大桥。
  - `03 溪谷江城`：峡谷穿行、双跨江斜拉特大桥与沿江山城路网。
  - `04 高新双城`：东西双城格局、中央湿地与立体跨线高架立交。
  - `05 自定义地图`：通过 `custom_map.json` 完全由玩家自建路网与景观，游戏内按 `R` 键即时热重载。
- **🛣️ 分级路网与拟真交规**：
  - 支持双向 2 / 4 / 6 / 8 车道分级、路口导向箭头、硬质防撞护栏与软路肩缓冲带。
  - **公交优先道**：八车道大道配置最外侧专用公交车道，AI 与狂暴模式公交优先走专用道，社会车辆仅允许临近路口右转借道。
  - **红绿灯与电子警察**：配备多相位信号灯、大路口独立左转灯头；红灯允许合法右转；监控龙门架抓拍直行逆行违章。
  - **环岛让行**：环岛取消红绿灯，严格执行“进环让行环内车辆”交规。
- **👥 乘客生态与车队协同**：
  - 普通车载客 45 人、双层车 80 人、铰接车 85 人；双层和铰接车基础加速度分别为普通车的 90% 和 85%。乘客“能上尽上”贪婪登车，仅生成当前线路可送达目的地的乘客。
  - 所有站台统一为长停靠区，车辆优先靠前停：可同时停两辆普通车／双层车，或一辆铰接车；两个泊位共享候车客流。详见 [双泊位说明](docs/station-berths-2026-10-23.md)。
  - 可在线路管理中为每条线路统一选择车型或分别设置三种车型的数量，合计配置 0～8 辆独立 AI 公交（具备专属涂装与车顶 LED 路线牌），协同营运同一城市。
  - **街区双侧设站与多线路**：内置城市长宽各扩大两倍，保持原有街区尺度。适合设站的大街区道路两侧各设站台，桥面、水域和死胡同不增设站；四城目前分别有 283 / 407 / 238 / 476 站。默认线路仍为 12 站，不要求覆盖全城。按 `T` 启用 1～6 条线路，分别配置每条线路的 **0～8 辆 AI 公交**与 **30～80 km/h 限速范围**，按 10 km/h 一档随机分配固定最高车速；调整范围会更新该线路现有车辆的限速，保留位置、乘客和营收。调整车数只增减该线路车辆，不重新调配其他线路。多条线路共用始发站时，玩家与 AI 公交沿同一站台前后排队、依次发车，换线和重置不会挤入已占用的车位。面板点击线路卡片编辑配置，点击“设为玩家运行线路”或回车选择玩家线路；点击“规划该线路”或在面板内按 `TAB` 直接规划所选线路，无需切换玩家线路；规划时按 `H` 显示／隐藏其他线路。

  - **固定随机限速**：设置中调整小车（默认 30～60，可设 30～100 km/h）限速上下限；AI 公交限速按线路独立配置（默认 30～50，可设 30～80 km/h）。按 10 km/h 一档随机分配，生成后固定；最低档跟车，其余车辆可在同向多车道安全超车，小车范围修改仅影响新生成车辆。双向双车道仅允许玩家公交在狂暴模式下借对向车道超车，小车和非玩家 AI 公交禁止逆行超车。
  - **路口防堵与恢复**：转弯、直行沿连续路线通过，路线不冲突可并行通行；出口回堵时在停止线外等待。小车清理和 AI 公交恢复至少等待连续原地堵塞两个完整信号周期；玩家车不会因堵塞自动重置。
- **🎥 多重视角与个性化定制**：
  - 支持 **车头朝上跟随**、**固定正北**、**固定正南** 三大摄像机视角（`V` 键切换）。
  - 支持 42px / 52px / 64px / 78px 自定义车道宽度，以及低 / 中 / 高 / 拥堵四档车流密度。
  - 完整支持**简体中文**与 **English** 双语界面，按 `L` 键秒级无缝切换。

## ⚙️ 游戏设置项 (Settings)

按 **`ESC`** 可随时呼出设置菜单调整选项：
1. **返回主菜单 / 更换城市**：随时保存状态并退回主菜单更换不同城市。
2. **违章抓拍与罚款开关**：可选择 `已开启 (违章扣$50)` 或 `已关闭 (无罚款)`。
3. **社会车辆交通流密度**：自由切换 `低 (144辆)` / `中 (288辆)` / `高 (576辆)` / `拥堵 (864辆)`。高车流感知与碰撞使用空间查询优化，见[864 辆回归与性能测试记录](docs/validation-864-2026-10-22.md)。
4. **摄像机视角**：切换 `固定正北 (标准)` / `车头朝上 (跟随)` / `固定正南 (倒置)`。
5. **公交驾驶模式与限速**：切换 `手动驾驶` / `AI标准巡航` / `AI狂暴极速`；统一调节 **60 / 80 / 100 / 120 km/h** 限速。
6. **路线 AI 公交车队与车型**：在线路管理中统一车型或混编普通车、双层车与铰接车，合计 0～8 辆；可单独选择各线路的玩家用车。运营中换车型会等待本圈终点站停车、全部下客后交接新车；减少数量的车辆也会跑完本圈再退役，待换、待退役状态随存档保存。车型外观和参数见 [车型说明](docs/bus-models-2026-10-23.md)。铰接车总长为普通车的两倍，前后两节通过铰点连接，尾节按车轴约束跟随转弯；跟车、变道和碰撞检查覆盖两节车身。
7. **界面语言**：无缝切换 `简体中文` 或 `English`。
8. **票价与运营统计**：点击设置页入口，或按 **O** 打开独立面板。

票价支持固定票价（0～10 元）、按站数、按里程三种方式。后两种方式可设 0～8 元起步价、包含站数或公里数，以及严格高于起步价且不超过 10 元的封顶。按站数超出包含范围后，每进入一组额外站数加 1 元；按里程的每公里票价为 0～10 元整数，总票价四舍五入。上车时按乘客目的地和规划道路里程收费，改价只影响之后上车的乘客。

统计面板显示当前线路各站间的道路里程、实际上下客数、玩家和各辆 AI 公交的车费收入、运营里程与完成圈数。均速完成首圈后显示，以已完成完整圈次的里程除以全部运营时间，包含等灯、堵车和靠站，暂停时间与重置打断的圈次除外。支持全部车辆和单车筛选，车辆列表标注所属线路；票价与圈速按各车自身线路里程计算。换地图或修改路线后重新统计。玩家换线保留其他车辆的营运数据。车费收入计入总营收，统计页不混入罚款。设置与统计可随本地存档保存。

### 本地存档

按 `F5` 保存当前进度（覆盖同一个存档槽），按 `F9` 读取存档。设置页也提供保存、读取按钮，主菜单的“继续存档”可在重新启动游戏后恢复进度。存档保留城市和自定义地图、所有线路与 AI 车队配置、车辆位置和乘客、客流、资金、票价与运营统计、游戏设置，以及正在编辑的线路。仿真从保存时的状态继续，关闭游戏期间不计运营时间。

存档位于系统用户配置目录的 `2d-bus-game/save.json`（macOS：`~/Library/Application Support/2d-bus-game/save.json`）。手动保存采用临时文件写入后替换，文件损坏或版本不兼容时会提示错误，当前游戏保持原样。本版本为手动存档，请在退出或开始新城市前保存需要保留的进度。

## 🗺️ 自定义地图指南 (Custom Map Guide)

项目根目录的 **`custom_map.json`** 支持玩家自由设计专属路网。游戏内置校验引擎，修改后在游戏内按 **`R`** 键即可**秒级免重启热重载**！

### JSON 示例速览
```json
{
  "name": "星空未来城",
  "subtitle": "自定义路网与生态客运网",
  "style": "metropolis",
  "roads": [
    { "name": "未来大道", "p1": [-2600, 0], "p2": [2600, 0], "lanes": 6 },
    { "name": "中轴路", "p1": [0, -1200], "p2": [0, 1200], "lanes": 4 }
  ],
  "stops": [
    { "id": 0, "name": "核心客运枢纽", "pos": [-600, 0], "heading": 0.0, "lanes": 6, "color": "#3B82F6", "capacity": 30 },
    { "id": 1, "name": "科技园北站", "pos": [600, 0], "heading": 0.0, "lanes": 6, "color": "#10B981", "capacity": 25 }
  ],
  "roundabouts": [
    { "name": "中央环岛", "center": [0, 0], "radius": 150.0, "inner_radius": 95.0, "type": "civic" }
  ]
}
```

> **设计要点**：
> - 道路端点 `p1` 与 `p2` 建议保持水平或垂直以构成规整路网。
> - 公交站点请设置在路段中段（距最近交叉路口中心建议 $\ge 240\text{px}$）。
> - 站点 `id: 0` 为始发站，开局公交车将自动停靠在该站点港湾中。

## 🚀 运行方法 (How to Run)

### 1. 源码直接运行 (推荐)
需要已安装 [Go 1.27.1+](https://go.dev/) 环境（版本与 `go.mod` 保持一致）：
```bash
go run .
# 或使用:
make dev
```

### 2. 编译并运行二进制文件
```bash
make run      # 一键编译并在终端启动
# 或手动编译:
go build -trimpath -ldflags="-s -w" -o busgame .
./busgame
```

### 3. 构建原生 macOS 应用包 (.app)
支持打包为带独立高分辨率 Retina 图标的 macOS 原生应用程序：
```bash
make open     # 编译 macOS 原生 App 并直接启动（在 Dock 中呈现高清图标）
make app      # 仅打包生成 "2D Bus Simulator.app"
```

Apple 芯片 Mac 配合 macOS Sonoma 14 或更新系统，可从此 `.app` 启动后点击窗口绿色按钮进入 macOS 原生全屏，让系统自动开启游戏模式。应用包已声明模拟游戏类别，并在 macOS 26+ 明确启用 `LSSupportsGameMode`。若之前为本游戏手动关闭过游戏模式，需要在游戏菜单／游戏叠层中重新开启一次；macOS 会记住该选择。直接运行命令行二进制不等同于从游戏应用包启动。详见 [Apple 游戏模式说明](https://support.apple.com/105118)。

M4 MacBook Air 的高车流测试、CPU 优化和 PGO／线程数实测见 [性能验证记录](docs/performance-m4-2026-10-24.md)。极限 48 辆 AI 铰接公交需要单独看实际画面长测，模拟基准不等于绘制帧率。

### 4. 运行测试
```bash
make test          # 基础快速测试（开发模式，秒级完成）
make test-qualify  # 全地图发布验收测试套件（覆盖 6 大城市多圈闭环巡航）
make test-all      # 运行全量单元与集成测试
```
