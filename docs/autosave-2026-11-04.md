# 自动存档与存档 metadata

Fast 和 Career 分别拥有 10 个手动槽位与最多 5 份自动存档；所有城市共用本模式的五份自动备份。运行中的有效游戏按五分钟实际经过时间保存，正常关窗或 Cmd+Q 退出时再保存本次运行中存在的两个独立会话。

F9 读取窗口提供“手动存档”和“自动存档”分页，也可按 Tab 切换。自动存档按时间从新到旧排列，通过五个固定物理文件轮换，成功原子写入后替代最老一份，不通过连环重命名移动其他代存档。手动槽位、名称与当前手动保存目标不受影响。

手动与自动存档都在文件头持久化模式、地图 ID／名称、BRT、大小路网、来源和自动保存原因。列表中名称与地图／模式并排显示，下一行显示实际保存时间和 BRT／4x 标记。旧档从有效负载推导缺失的地图和模式信息，不要求迁移；复制文件或更名不会替换原保存时间。

首次开始游戏或修改生涯之前不保存空白开局。读取存档列表和编辑站名时会延后定时保存，避免选择中的自动存档被轮换。生涯在菜单中未改排班时保留暂停前的旅程；排班或玩家车已改变时准备下一次调度快照，并保持当前菜单和选图。

退出写入失败时不关闭游戏，显示错误并允许再次关闭重试；失败写入保留已有五代文件。

- Fast／Career 分别轮换八次，保留最新五代并逐份恢复，确认模式隔离及手动文件原字节不变。
- 模拟五分钟计时、失败写入、重试限频及恢复，确认失败未破坏任何一代文件。
- 退出同时保存两个模式，重复退出处理不重复写入；失败退出可重试。
- metadata 持久化、旧档补充显示、复制文件时间、更名、自动读取后保留手动目标槽位。
- 菜单、空白开局和未启用自动存档的测试实例保护，以及生涯菜单下的旅程保留。
