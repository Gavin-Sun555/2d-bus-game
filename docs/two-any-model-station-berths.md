# 两辆任意车型同时靠站

标准站台仍为原有长度，不加长绘制区域或物理边界。

- 普通车、双层车和铰接车可任意组合，占用前后两个泊位。
- 前车仍优先靠站台前端；后车根据前车真实尾部位置，保留原有的
  安全间距，而非统一按普通车长度定位。
- 后车车尾可以超出站台后端。车头段到达停靠区域、方向和横向位置
  合理、实际完整车身没有碰撞时，允许开门上下客。
- 第二辆已经在港湾内的车不会再因为“铰接车独占整站”而一直等待。
  读取旧存档中已到位的等待计划，也会重新按这个规则判定。
- 第三辆继续排队，车辆碰撞检测、道路边界、上下客最短时长、各车型
  上下客速率及共享站台乘客池保持原有规则。手动玩家也不能在已有两辆
  公交上下客时再占用第三个泊位。
- 狂暴模式原有的外侧道路靠站选择保留；本次放宽车尾越界针对港湾
  内的后泊位，不放宽道路外侧的完整车长检查。
