# 绿灯等待诊断

AI 公交在停止线前、所在方向直行绿灯亮起后，连续静止 1.5 秒，会自动保存一次交通快照。关门上下客和正常远处排队不触发；一次连续等待只写一次。此机制只记录，不改变信号、碰撞、让行和重置规则。

macOS 文件位置：`~/Library/Caches/2d-bus-game/green-wait.json`。每辆车保留最近一次事件，包含采集时间、地图、车辆位置、目标站、路口相位、已生成的路线、控制器状态，以及信号、前车、路口准入、转弯扫掠等制动约束。`Limits` 中负数表示不受该项限制。`Blockers` 列出单独就能令当前车辆停下的障碍；它们不一定违法或应被忽略。换地图或改路线后，内存中的事件与等待计时重新开始。

直行绿灯下，合法等待左转红灯的车辆也可能被记录，须结合路线和 `signal` 约束判断。快照用于区分信号选错、真实出口拥堵、路径预占以及站点状态等问题，不能单凭快照出现就认定应该强行通行。

`BUSGAME_TECH_PROBE=1 go test ./game -run TestProbeTechGreen -count=1` 可运行科技创新园区出站后的多随机种子车流检查。普通回归测试覆盖关门出站后首轮绿灯、公交专用道信号切换和三车队列起步。
