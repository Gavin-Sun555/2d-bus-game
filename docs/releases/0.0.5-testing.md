测试日期：2026-10-19。环境：macOS / Apple Silicon arm64、Go 1.27.1、Ebitengine 2.10.4。

**湖畔水乡和高新双城的两项发布前高优先级风险已修复。** 相同随机种子、车流和限速复测，两分钟结束车况分别由 58% / 60% 提升至 100% / 100%，并保持正常行驶进度。现代都会狂暴模式仍有一次车辆接触，完整自动驾驶零碰撞验收尚未达成。本报告记录发布前的本地验证；正式版本由 `v0.0.5` tag 的 GitHub Actions 流程测试、构建并发布。

### 两项高优先级风险的修复与回归

1. **湖畔水乡：窄路环岛出口、借道超车及转弯侧擦。** 原始环岛圆弧与出口直线存在接近直角的折点，长车车头侵入对向候驶队列。出口改为提前接入连续曲线，检查转向曲率、整车道路净空及驶出方向的中心线。窄路借道按狂暴巡航速度和实际对向车速预留 4.5 秒的超车、回归时间；避障只计入同向速度投影，避免把对向车速误当作前车速度。另补上路口转弯的整车扫掠与车辆未来位置检查，避免中心点分属不同车道但车头仍侧擦的情况。
2. **高新双城：高速贴近中心线时突然向右打满。** 原保护逻辑要求立即获得 2 px 净空，找不到满足条件的输入就返回满舵右转。现在先寻找 2 px 余量，再允许至少 0.25 px 的物理净空恢复；所有预测都不可行时减速并限制转向，避免横穿车道撞护栏。道路轴线与路径不符时不套用直路中心线保护。
3. **回归发现的漏站续行问题。** 漏站切换下一站时，复用旧的车道偏移会把车辆拉向新出站曲线的错误一侧。现在与飞站一致，从车辆实际车道衔接后续路径，保留继续行驶、不跨中心线的集成断言。

4. **起点出站斜线绕过中心线保护。** 出站路径斜向并入行车道，原先的路径轴线检查会把这段渐变路径排除。现在根据始发站的道路中心、方向和出站距离识别同一道路，在渐变段也执行完整车身预测和安全恢复。新增四方向失败重现用例（修复前错误允许继续向左打满）、48 组带前车的真实车身出站测试，以及 48 组真实游戏启动测试：四档车流、四种车道宽度、三个种子，先以手动模式运行四秒后再启用 120 km/h 狂暴驾驶，检查完整车身不跨中心线且实际驶离起点。

专项测试覆盖四个方向、四种车道宽度与 4/6/8 车道的高速小净空及不可行恢复、借道加速与回归时间、对向车辆速度投影、转弯车头碰撞/相邻安全车道、四个方向的环岛出口整车净空。原先“安全相邻车辆”的左转用例车头实际朝向对向车辆，已纠正该用例方向，并新增原错误方向必须制动的独立断言。

真实游戏协调器长测新增硬性门槛：地图 3 / 4 狂暴模式每次更新都不得发生车况下降，120 秒内累计行程必须超过 10,000 px，防止通过停车等待掩盖碰撞。两场实际行程分别约 12,315 / 14,087 px。上述条件已进入 `make test-soak`，也会在发布 CI 执行。

本机后台负载会影响耗时，这些数字用于本次相对比较，不是最低配置或 FPS 承诺。每帧分配字节数减少约 97.5%–99.4%。该基准测量小车更新及对公交的感知，不包含整套车队控制、玩家、HUD 或 GPU 绘制。

改动：

- 只在到达弧线切点后生成小车转弯路径，避免每帧为远处路口分配、采样曲线。
- 小车感知的公交列表使用栈上固定容量；玩家及车队复用观察缓冲区。
- 跟车距离使用平方距离预筛选，当前车辆的方向三角函数只计算一次。
- 信号灯几何按车道宽度、道路连接及车道数缓存；增加配置变化的失效回归测试。

### 渲染

使用真正的 Ebitengine `Update/Draw` 回调采样。固定高新双城、288 辆小车、8 辆 AI 公交、1280×720、缩放 0.6，冻结仿真以保持画面一致：

- 优化前绘制提交平均约 **93.39 ms/帧**。
- 仅信号灯/车辆裁剪后约 **47.94 ms/帧**。
- 道路和虚线可视范围优化后约 **44.42 ms/帧**，降低约 **52.4%**。
- 优化前后 RGB 截图逐像素对比一致，未通过移除可见细节换取性能。

这是 CPU 绘制提交的墙钟时间，**不是 GPU 耗时，也不是最终 FPS**；该场景仍有继续优化空间。检查工具会跳过首 10 次预热更新，并分别记录更新次数和绘制次数。

改动：屏幕外信号灯在矢量细分前剔除；车辆裁剪保留完整灯光范围；道路及矩形使用更准确的包围盒；虚线只生成可见范围，保持原相位并支持旋转相机。旋转、缩放下虚线不漏绘另有自动化测试。

当前 CI 的负载测试阻止崩溃和非法状态，并将本次地图 3 / 4 狂暴场景的任何车况下降或明显进度不足视为失败。其余场景仍记录实际碰撞扣损，不能用绿色 CI 取代全部交通安全判断。
