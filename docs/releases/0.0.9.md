# 0.0.9

本版增加中央 BRT 地图选项与专用右转信号，修复狂暴模式的前车识别和右转并线摇晃，并完善多线路乘客、道路选项、界面和场景绘制。

- 中央 BRT 仅应用于原有公交专用道的双向八车道路段；各地图独立开关，含合规自定义地图。修改地图选项并重新进入会重置本局。
- 中央右转与横向左转同期放行，右侧道路空闲且可安全并线时可从最右侧右转。
- 修复零 AI 公交配置下玩家自动驾驶看不到小车、以及提前并入右转车道后反复摆动的问题。
- 发布长测发现并修复中央 BRT 超车后车身尚未回到目标车道却继续高速巡航的问题，增加减速回正保护。
- 保留三种公交车型、独立线路、十槽存档和旧存档兼容。

本地发布验收已通过，状态为 `LOCAL_PASS_PENDING_PLATFORM_CI`。详细结果见 [发布验收报告](0.0.9-testing.md)。平台构建不等于对应平台已完成原生运行测试；公开发布仍需发布工作流通过。
