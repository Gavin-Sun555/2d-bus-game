# 0.0.6 发布资格测试报告

**最新结论：三项已记录风险已修复，本机完整复测通过。** 详见 [专项复测报告](0.0.6-risks.md)。下文保留修复前的首轮验收结果及失败证据。

测试日期：2026-10-22；macOS Apple Silicon arm64，Go 1.27.1，Ebitengine 2.10.4。测试对象为当前工作区候选源码，含尚未提交的功能与修复。

## 首轮结论（修复前）：暂缓正式发布

功能回归、竞态检测、稳定性长测通过，可以供本机候选体验；**交通安全仍存在可复现碰撞，尚不能签署无阻塞的发布验收**。4×视野绘制成本也明显偏高。本轮准备 0.0.6 版本、说明与本地候选包，不创建远端 tag 或发布。

### 待处理的发布风险

1. **P1：溪谷江城狂暴模式碰撞。** 标准长测种子 502，102.33 秒，玩家位置约 `(415, -1755)`，航向 0.30、速度 103.5 px/s，车况 100→97。最近记录的小车 #312 位于 `(399, -1721)`，速度 0；它只是最近车辆记录，不能据此认定必然是碰撞对象。需针对该时刻回放完整车辆扫掠与路权。
2. **P1：高限速混合交通碰撞。** 现代都会种子 91、湖畔水乡种子 94 的 120 秒场景分别结束于 94% / 91%。相同条件回放再次得到一致车况：现代都会在 107.82 秒、约 `(6384, -3536)` 扣损；湖畔水乡在 112.63 秒、约 `(6451, -1820)` 与 114.75 秒、约 `(6448, -1814)` 两次扣损。需定位实际接触原因并保持相同车流、种子、车速复测。
3. **P2：广角绘制负载。** 2×/4×视野的 CPU 绘制提交约 52.96 / 81.09 ms；常规六地图场景约 7.36～16.20 ms。需继续分析更大可视范围下道路、车辆和矢量灯光成本。此轮图形测量与其他检查并发，数字用于发现风险，不作为独立设备性能承诺。
