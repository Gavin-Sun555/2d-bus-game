# 0.0.4

本版整理项目架构，并修复狂暴模式下的环岛入口和左转车道通行问题。

## 更新

- 将游戏组织代码与仿真模型、自动驾驶、交通车流、渲染、界面和本地化拆分为独立包，按职责拆分大文件，并补充架构说明。
- 修复双向四车道内侧进入环岛时的转向和车道保持，避免过早返回外侧车道及车身切入中心岛。
- 汇入环岛前预测内环车辆沿圆弧的位置及公交到达时间，有冲突时在入口外让行，安全间隙出现后继续驶入。
- 修复进入最左侧左转车道时，把直行车道队列误判成前方阻挡的问题。按路径检查完整车身间隙，保留真正阻挡及红灯停车判断。
- 保留统一 45 人容量、连续上客、线路内乘客生成、路口净空和死锁恢复功能。
- 补充跨平台自动测试、发布包和 SHA-256 校验文件。

## 验证

- 本地全量测试（含子测试）561 项通过，无失败或跳过；使用 `-race -count=1` 执行并生成覆盖率报告。
- 六张地图的发布验收通过，覆盖普通及狂暴自动驾驶、超车、交通车流、AI 公交车队、地图边界和中英界面。
- 回归验证内侧环岛入口、96 组环岛车流让行，以及四个方向的左转车道误停和红灯停车。
- `go vet ./...`、`go mod verify` 和补丁格式检查通过。
- 发布流水线在 Linux 上重复全量测试与竞态检测，通过后才构建并发布四个平台包。

## 下载

选择对应系统的 ZIP，解压后运行 `busgame`、`busgame.exe` 或 macOS 的 `2D Bus Simulator.app`。提供 macOS Apple Silicon / Intel、Windows x64 和 Linux x64 构建。

macOS 包未使用 Apple Developer ID 签名或公证。Linux 需要支持 OpenGL 的图形桌面环境。压缩包包含自定义地图、使用说明和架构文档。

---

This release separates simulation, autopilot, traffic, rendering and UI packages; fixes inner-lane roundabout entry and yielding to circulating traffic; and prevents false stops beside through-lane queues when merging into a left-turn lane. Existing passenger, intersection-clearance and deadlock-recovery features are preserved.
