# 0.0.5

本版新增八车道道路及公交专用道，丰富城市风貌，并集中修复自动驾驶的环岛、转弯、靠站和车道选择问题。详细测试结果、性能数据和已知问题见 [发布测试报告](https://github.com/Gavin-Sun555/2d-bus-game/blob/v0.0.5/docs/releases/0.0.5-testing.md)。

## 玩法与地图

- 新增每方向四车道的普通道路，以及每方向三条普通车道加一条公交专用道的道路。
- 公交优先使用公交专用道，可为超车或较短信号队列使用普通车道；社会车辆只在路口右转时使用公交专用道。
- 车流统一为低、中、高、拥堵四档，分别为 36、72、144、288 辆。
- 五张预设城市增加独立配色、地表、建筑、植被、水景和桥梁风貌，保留自定义地图。

## 驾驶与交通修复

- 改善环岛入口让行、候驶小车的停车距离、进出弯轨迹及车道保持；窄路出口提前衔接整车净空曲线。
- 借道超车预留加速及安全回归时间，修正对向车辆速度判断；转弯检查完整车身扫掠。
- 高速车道保护无法获得安全转向时减速恢复，避免直接向右打满撞护栏；始发站斜向出站时同样保持中心线保护，漏站后从实际车道继续行驶。
- 外侧车道优先驶出环岛；确实无法安全驶出时继续绕行，避免强行转向。
- 改善左转准备、对向左转路径、宽窄道路衔接及右转驶入对向车道的问题。
- 修复右转及变道后通过路口时的红灯误判；小车右转允许红灯通行，保留让行和净空检查。
- 靠站优先选择靠近站台的可用车道；满足飞站条件时保持通行，不为车站减速或变道。
- 最右侧车道的小车在有安全制动距离时为公交靠站、出站创造间隙；公交变道受阻时保持当前走廊。
- 公交回起点、小车卡死移除都需要独立、连续的原地卡死时间，至少为最近路口完整信号周期的 1.5 倍。标准大路口为 55.5 秒，路口附近不再使用 4 秒快捷恢复。
- 小车在整车驶出地图后离场，再从其他随机路口安全生成替代车辆；没有安全空间时稍后重试。

## 性能与发布工程

- 到达转弯切点后再生成小车转弯路径，复用公交观察列表，减少频繁的堆分配。
- 缓存信号灯路口几何尺寸，并在车道宽度或道路配置变化时重新计算。
- 提前剔除屏幕外信号灯、车辆、道路及景物；只生成可视范围内的道路虚线，并保持原有虚线相位。
- 新增 `make bench`、`make test-soak` 和 `go run ./cmd/release-check`。
- `VERSION` 统一应用标题、macOS bundle 和发布包版本；CI 检查 tag 与版本、发布说明一致。

## 已知问题与验证范围

湖畔水乡及高新双城两项高优先级碰撞风险已修复，相同拥堵车流、8 辆 AI 公交、120 km/h 的两分钟狂暴长测均保持 100% 车况。现代都会同等长测仍有一次碰撞扣损，不能宣称自动驾驶已实现全场景零碰撞。具体风险和平台验证范围见测试报告。

## 安装

下载对应平台 ZIP 并完整解压。macOS 运行 `2D Bus Simulator.app`，Windows 运行 `busgame.exe`，Linux 运行 `busgame`。发布包附带使用说明、自定义地图和 SHA-256 校验文件。

macOS 应用未经过 Apple Developer ID 签名或公证；Linux 构建需要图形桌面及相应系统依赖。

This release adds eight-lane roads and optional bus lanes, four traffic densities, distinct city scenery, and fixes for roundabouts, turns, red-light classification, docking and bus priority. The Emerald Lake and Twin Cities release blockers are fixed: both full-load 120 km/h Berserk endurance replays retain 100% durability. A remaining Metropolis contact is documented in the test report, together with platform validation limits.
