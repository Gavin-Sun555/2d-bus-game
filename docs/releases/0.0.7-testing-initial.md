> 后续更新：首次验收的三组 P1 碰撞已修复并按原始存档、种子复测，详见 [P1 修复验证](0.0.7-p1-fixes.md)。自定义铰接车仍存在环岛互等，原 P2 进度和最大车队性能问题也未解除。下文保留首次验收结果；其中候选 ZIP 为修复前产物。

## 结论：暂缓正式发布

本轮完整验收已完成。常规回归、发布专项、补跑后的完整竞态用例覆盖、旧存档绿灯卡点回放及三平台候选包校验通过；**高车流长测仍有三组可复现碰撞和一项行驶进度门槛失败**。48 辆 AI 铰接车的最大配置性能也明显不足。因此，0.0.7 当前候选不能判定为发布通过。

测试日期：2026-10-23。Apple M4、macOS 27.0.1、Go 1.27.1、Ebitengine 2.10.4。测试对象为当前尚未提交的工作区源码，`VERSION` 已准备为 `0.0.7`。本轮没有创建远端 tag 或发布 GitHub Release。

## 长测结果与发布阻塞

共执行 21 个场景：六地图普通／狂暴 12 场、最高 AI 限速 3 场、混合车型 6 场；每场计划 120 秒仿真，碰撞断言失败的场景提前结束。按本轮安全与进度门槛汇总，17 场符合条件，4 场未通过。

旧长测只对部分地图的扣损立即失败，自定义普通场景首次虽被测试程序记为通过，却记录了 97% 车况。本轮将所有地图的玩家扣损统一升级为失败，并对该场景单独复测，稳定失败。不能将首次测试名的“通过”当作交通安全通过。

在其他重负载测试结束后单独运行，都会地图、864 小车、4×视野，玩家与全部 AI 均为铰接车，AI 30–80 km/h，seed 5。每场先预热 600 次更新，再计量约 1,200 次更新对应的实际绘制。

**P2：48 辆 AI 铰接车最大配置仍明显不流畅。** 8 辆结果接近 60 FPS，但不能推广到六条满编铰接车线路。应继续优化或明确配置边界后再确认性能验收。数字为有限场景的本机测量；Update 不包含 GPU 执行时间，绘制帧率来自真实回调计数。

## 本轮已修正的发布流程问题

- ZIP 打包器补齐模拟游戏类别和 `LSSupportsGameMode`，避免正式 ZIP 丢失本地 `.app` 已有的游戏模式支持；验证脚本新增对应硬性检查。
- 增加六地图混合车队与中途存读档长测、捕获存档短回放入口；所有地图的玩家扣损都会使安全长测失败。
- `make test-soak` 纳入 0.0.7 混合车型矩阵，并增加运行预算；保留原有全地图普通／狂暴和最高 AI 限速场景。
