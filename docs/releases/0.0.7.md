# 0.0.7 候选版本

**发布验收暂缓（HOLD）：隔离回放确认两组公交控制互锁（正常拥堵及等待时长本身不阻塞发布），最终全屏绘制间隔 P99 也未达检查线。尚未正式发布。** 详见 [最终验收报告](0.0.7-testing.md)。

- 更大的四座城市，1～6 条独立线路，逐线规划、AI 数量及限速设置。
- 普通车 45 人、双层车 80 人、铰接车 85 人；支持混编数量、玩家车型设置及终点换车。铰接车采用两节车身与尾节跟随物理。
- 统一长站台、跨线路排队，改善狂暴模式进出站、站台旁停靠与飞站。
- 本地存档（F5／F9），兼容旧存档、车型交接和运营状态。
- 修复八车道左转、绿灯等待、必要并线、环岛排队及停站互等。
- 拥堵档 864 辆小车，空间查询、车道候选、车身预测缓存及绘制缓冲优化；加载阶段预热曲线绘制管线。
- 运营统计、线路管理、两行 HUD、Mac 全屏比例及 Game Mode 支持改进。

测试结果、平台覆盖与限制见 [发布验收报告](0.0.7-testing.md)。macOS 下载包未作开发者签名／公证。
