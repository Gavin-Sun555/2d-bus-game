# 0.0.7

本版扩展线路运营与车辆配置，加入真实两节铰接车、最多 10 份独立存档，并集中修复公交通行、站台排队和旧存档恢复问题。

- 四座主要城市扩大至原面积的四倍，支持 1～6 条独立线路及逐线规划、混编车队与限速设置。
- 普通车载客 45 人、双层车 80 人、铰接车 85 人；运营中换车在本圈终点停车、下客后交接。铰接车约为普通车两倍长，前后两节通过铰点跟随转弯。
- 统一长站台，可同时容纳两辆普通/双层车或一辆铰接车；改善前泊位停靠、跨线路排队、狂暴模式站台旁停靠与进出站路径。
- **最多 10 份本地存档**：F5 选择槽位保存，F9 选择存档读取，显示保存时间、覆盖确认，打开时暂停游戏。原有存档作为槽位 1 保留，损坏文件读取失败时不替换当前游戏。
- 修复八车道左转、绿灯不走、多车道必要并线、环岛排队、公交互锁和后车跟车过近；玩家自动驾驶参与小车让行调度，保留完整车身及制动距离检查。
- 修复旧存档飞站离站偏移多算一条车道宽导致卡死，读档后可自动恢复。
- 拥堵档为 864 辆小车；空间索引、车道候选、车身预测、保守分组筛选、精确姿态缓存和圆形绘制缓冲优化。加载阶段预热曲线绘制管线。
- 改善运营统计、路线规划、顶部两行 HUD、Mac 全屏比例及 Game Mode 元数据。

## 已知性能限制

M4 MacBook Air 在最大 48 辆 AI 铰接公交、864 辆小车与广角视野的压力场景中，慢帧仍未达到原定 benchmark，可能出现卡顿。通常负载下的可玩体验由用户确认可接受，因此本版接受这一已知限制并发布，继续优化留到下一版。**不保证更高性能电脑或所有配置均稳定 60 FPS。** 正常高密度拥堵与逻辑互锁分开处理，等待时长本身不判为缺陷。

测试、平台覆盖及发布决策详见 [发布验收报告](0.0.7-testing.md)。本版 macOS 下载包未作开发者签名/公证。
