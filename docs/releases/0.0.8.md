# 0.0.8

本版新增大路网模式、存档自定义命名与删除管理、开局即时生效的车型配置，全面升级八车道公交专用道借道超车与公交信号优先（BSP），并重点修复了终点站换车卡死与高密度车流排队通行问题。

- **大路网模式 (Large Road Network Mode)**：保持第一张地图（Metropolis）的街区拓扑格局与站点关系完全不变，将路口到路口的街区长度扩展至原有的 4 倍，带来更开阔的大都市尺度与长距离巡航体验，全面适配公交加减速、巡航限速与信号灯周期。
- **存档命名与删除管理**：在 F5（保存）和 F9（读取）界面新增存档槽位命名/重命名（R / Enter）与删除功能（Delete / Backspace），附带二次确认防误触弹窗与中英文支持，完美兼容既有存档。
- **开局即生效的玩家车型设置**：解决在设置面板中设定为双层车或铰接车后新游戏开局仍为普通车的时序问题，新开局或加载直接应用当前设定车型；中途调整车型保持在完成整圈并回到终点站下客后交接。
- **终点站换车与卡死问题修复**：
  - 修复存档一（slot1）中公交进起点站换铰接车时卡死的问题：支持开门触发 `AdvanceToNextStop()` 提前切站场景下的终点站上下文识别，彻底消除换车逻辑失效导致的停滞。
  - 在车门关闭与离站逻辑中增加保持释放兜底，防止意外滞留的换车刹车保持永久锁定车辆。
- **八车道公交专用道借道超车**：
  - 修复存档二（slot2）中狂暴模式 AI 公交在八车道公交专用道（120 km/h 巡航）跟在慢速 AI 公交（80 km/h）后方不超车的问题。
  - 重构专用道评分模型 `busLaneTrafficScore`，结合期望巡航速度与前车相对距离进行阻塞惩罚评估；在左侧相邻车道有安全间隙时果断借道超车，超越后平滑返回最右侧公交专用道。
- **公交信号优先系统 (Bus Signal Priority)**：
  - 引入公交信号优先逻辑：检测接近停止线的公交车流，支持绿灯延长（Green Extension）与红灯早断（Red Truncation），减少公交路口延误。
- **站点语音播报系统 (Station Voice Announcements)**：
  - 增加进出站语音广播与 HUD 报站文字提示联动，提升运营沉浸感。
- **站台排队与自愈改进**：优化双铰接车长站台排队进出、转弯衔接扫掠与防死锁回正，保障大车流下高密度运营的自主通行。
