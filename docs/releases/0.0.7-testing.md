# 0.0.7 最终发布验收

测试：2026-10-26～27。结论：**暂缓发布：最终原生长测未通过全部门槛**。原生性能、覆盖率及完整竞态数据属于基线提交 `423a3e8`；尚未发布正式 GitHub Release。

2026-10-27 优先权补充：正常拥堵可接受，等待时间本身不作为发布阻塞。最新修正覆盖全部跨越车道的小车让行，并保留玩家自动驾驶的优先确认；全量回归 10,052 项通过、专项竞态 680 项通过、21 个长测场景通过。本次未重跑全套竞态或 15 分钟原生性能；详细因果隔离及验证见 [公交优先权报告](../bus-priority-qualification-2026-10-27.md)。

## 本轮发现并修复的通行阻塞

首次 15 分钟原生采样性能过线，但玩家最长等待 336.38 秒，整体判定 HOLD，原数据保留在 `native-before-blocker-fix/`。根因是跨多车道并线的后车让行只认最终车道，且玩家自动驾驶没有发布与 AI 相同的让行确认。现在对全部跨越车道发布安全后方空隙，仍保留完整车身及制动距离检查；手动驾驶撤销自动让行承诺。

原结束现场回放 120 秒：玩家 15,500.8 px，前方 AI 46 行驶 16,349.0 px，最长等待 20.15 秒，目标站 7→1；玩家与全部 48 辆 AI 均无新增损伤。回放重建世界、车辆、司机与灯态，不完整重建所有运营随机状态，不能当作逐位重播。

自定义地图的第二处卡点已通过狂暴模式正确的始发站出站路径预防；修复前开发版已形成的偏离轨迹存档不在该新建场景验证的恢复保证内。

## 最终原生全屏性能

M4 MacBook Air，16 GiB，macOS 27.0.1，Go 1.27.1，Ebitengine 2.10.4，接电，Metal，4 倍驾驶视野、1280×804 逻辑画布。48 辆 AI 与玩家均为铰接车，六线路，拥堵档目标 864 小车。测量独立运行 900 秒，分析第 30～900 秒全部回调，不并行运行重型测试，不启用 profiler／trace。实际小车数量范围 755～864，不能视作始终恰好 864 辆。

本轮沿用性能研究提出的检查线：TPS ≥59、Draw FPS ≥58、间隔 P99 ≤25 ms、P99.9 ≤50 ms、超过 100 ms 的间隔必须复核；另审查停车超过 120 秒及任何公交扣损。分项结果见 [结构化数据](0.0.7-qualification.json)。这些是有限场景的本机检查线，不是所有设备的帧率保证。Draw 提交时间不代表 GPU 执行时间，回调间隔不等于显示器实际呈现时间。Game Mode 开启状态未在本轮单独观测。

本轮完整竞态曾因收窄修改范围而主动中止一次；该不完整运行留在 `superseded-unrestricted-bay-fix/`，不计为最终通过。最终表格只使用重新执行的完整结果。

此前第一次自动启动报 `no monitor was found`，没有产生有效帧数据；已剔除，不能用 `open` 的返回码当作游戏成功运行。

## 最新通行修复与剩余发布阻塞

- **P1 已关闭：两组公交控制互锁。** AI 18／23 的出站与并线依赖通过站湾侧安全回正解除；AI 19／20 的外包矩形误拦截改为真实前后节扫掠。8 个现场组合、顺序互换及中途读档均通过，完整 48 AI／小车现场的原 11 辆长等公交也全部恢复进展。最新全量回归 10,072 项、专项竞态 253 项、21 场长测通过；详见 [互锁修复报告](../bus-interlock-fix-2026-10-27.md)。正常拥堵和等待时长本身不作为发布阻塞。
- **P2：慢帧仍超过检查线。** 绘制间隔 P99 为 31.08 ms，超过本轮提出的 25 ms；P99.9 为 49.49 ms，最长 94.73 ms，超过 50 ms 共 42 次，约每分钟 2.9 次。平均 59.24 FPS 不能单独构成发布通过。

因此本轮完成了候选测试和两个定点修复，但**不建议正式发布 0.0.7**。当前状态为 HOLD，PR 应保持草稿；已在发布工作流增加资格判定检查，HOLD 数据会阻止标签触发的公开发布。后续需复核慢帧，并更新同一候选的资格数据。
