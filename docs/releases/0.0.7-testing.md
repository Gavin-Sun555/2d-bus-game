## 已知性能限制与明确接受

性能仍未完全达到原定检查线。最近一次有效 15 分钟原生 P2 试验的 Draw gap P99/P99.9 为 31.138/59.653 ms，最长 106.659 ms；该数据早于最后的十槽存档、存档恢复与姿态缓存调整，**没有冒充最终标签的新原生长测**。最终缓存短窗口耗时减少约 0.25%～0.69%，不能据此认定慢帧已解决。详情见 [P2 长测与实验](../performance-p2-experiment-2026-10-27.md)、[精确缓存实验](../performance-pose-cache-2026-10-27.md)。

用户在最终发布请求中明确确认：非极端负载的可玩体验可以接受，性能优化留到下一版。因此 P2 作为已接受风险发布，不把 benchmark 改写为通过，也不保证更高性能电脑或所有负载稳定 60 FPS。

## 最终 CI 与发布包

此前 e6ab238 的 Linux 全套竞态运行超过 90 分钟后被测试超时终止，日志没有报告断言失败。现在按包名与顶层测试名的稳定哈希分为 8 个独立作业；保留所有普通、示例、fuzz 种子及子测试，并执行 -race。无测试包也在分片 0 进行 race 构建。全部 8 个分片、完整常规覆盖率、发布专项与长测通过后，才允许构建四个平台包。

发布包含 macOS Apple Silicon、macOS Intel、Windows x64、Linux x64 ZIP 与 SHA256。每包检查版本、架构、ZIP 完整性、文档、自定义地图及校验和；macOS 另检查图标、可执行位、游戏类别及 Game Mode 元数据。macOS 包未经开发者签名/公证；Intel 和 Windows 未声称进行本机游戏运行验证。

相同提交的重复 PR/标签工作流会取消旧运行，最终标签仍完整执行全部门槛。发布脚本依赖全部测试与四平台构建成功，再校验当前资格报告并公开 Release。作者、提交者与标签身份为 Gavin Sun / Gavin-Sun555，未使用 Codex 身份。
