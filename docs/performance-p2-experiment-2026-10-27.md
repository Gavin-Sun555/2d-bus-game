# P2 优化试验与重新采样（2026-10-27）

已完成：新版 15 分钟基线 → 单独试方案 1 → 方案 2 → 最终组合 15 分钟复采样。基于 `e6ab238`，所有修改仅在本地，未提交或推送 GitHub。

## 保留与撤回

| 试验 | 三次交替固定模拟的中位耗时 | 决定 |
|---|---|---|
| 1a：路口发布时预计算段长／方向 | 10.997 → 11.149 ms，慢 1.38% | 撤回；一致性通过不代表有净收益 |
| 1b：连续采样体的保守分组包围范围 | 10.900 → 10.678 ms，少 2.03% | 保留，三组均有改善 |
| 2：额外半径／轴缓存结构 | 10.683 → 10.659 ms，少约 0.23% | 撤回额外结构；整场收益不足以支持增加实现复杂度 |
| 2 简化版：仅复用既有方向得到垂直轴 | 10.697 → 10.659 ms，少约 0.36% | 保留两行改动，三组均小幅改善；不据此声称稳定帧率提升 |

每项使用独立冻结测试二进制，最大车队、864 小车、固定种子，每进程预热 300 tick、测量 1800 tick；顺序 A→B→B→A→A→B。正式计时无 profiler、无并行回归。不同阶段百分比不能相加，也不能将这些短窗口平均 Update 时间当作原生全屏延迟。

最终生产改动仅在 `junction_traffic.go`、新增 `corridor_groups.go` 与 `types.go`。没有加入跨帧派生缓存、半径缓存、修改姿态积分或线程模型。

- 路口采样体按原顺序每 8 个分组，用半长＋半宽的保守方形范围及向外浮点余量筛选。只有整组确定分离才跳过，其他情况继续原圆形粗筛和 SAT；短数组、超过 512 个目标采样体或异常坐标／尺寸沿用全扫描。局部组存储有界，不跨调用保存。
- OBB 垂直轴由已经计算出的单位方向构造，保留原四轴投影、余量、比较顺序、法线及深度。未使用近似三角函数或平方距离替换。

## 验证

常规回归 10,077 项通过、24 项默认跳过；专项竞态 347 项通过；六地图 21 个长测叶场景全部通过，共 42 分钟仿真。全量回归包含两组公交互锁的捕获状态与中途读档；本轮未重跑整套 race。

原版、仅 1b、最终组合各推进 1800 tick，逐帧轨迹文件 SHA-256 均为 `9c9370f2825fe913e841cbdc53b9764085099060ab7597427f0248a718e32630`。对照涵盖全部小车、公交姿态与速度、路线进度及乘客等已记录字段，不宣称覆盖全部内部状态。

新增独立原实现 oracle：3000 组随机走廊及接触／异常数据回退对照；20 万组碰撞配对比较碰撞布尔、法线与深度位模式；25 万个原始浮点角度样本检查垂直轴一致性。目标函数微基准中，碰撞例子约 25.52 → 20.03 ns；最终组合的嵌套弧线分离例子约 9722 → 2549 ns。微基准收益不代表整场同比提升。

## 结论

两项小改动降低了固定模拟计算成本，但本次原生性能仍未通过全部检查线，P2 不能宣布关闭。保留有对照收益的小改动，后续应根据慢帧区间跟踪决定下一步，而不是自动叠加方案 3、4。

此前在第 258 秒失焦的试跑已中止，保留在 `baseline-invalid-focus-258s/`，不计入以上性能数据。后续基线按用户确认重新完整运行。

原始证据在 `dist/p2-experiment-2026-10-27/`，包括全部失败原型、冻结二进制、交替基准、逐帧哈希、回归输出和两轮原生数据。结构化数据见 [JSON](performance-p2-experiment-2026-10-27.json)。用户存档原件 SHA-256 保持不变。

## 复采样后剩余慢帧与热点

基线超过 25 ms 的间隔为 714 次，最终组合为 567 次；这些间隔全部包含至少两次 Update。最终最长间隔发生在约 235.89 秒：5 次 Update 合计约 104.15 ms，回调外剩余约 0.97 ms。基线在约 235.98 秒也有几乎同样的 106.64 ms 间隔，不能说本轮消除了这个慢场景。

基线独有的 146.38 ms 最长事件约在 31.87 秒，其中约 84.59 ms 位于 Update/Draw 回调之外；候选中没有同样的最大事件，但没有该帧的系统／图形跟踪，不能将最长间隔的全部差值归因于两项算法优化。
