# 存档二交通死锁修复与长测（2026-11-15）

场景来自本机最新 `save-02.json`，名称“现代都会小路网非BRT”。测试前复制到 `dist/slot2-validation-2026-11-15/original-slot2.json`，不覆盖手动存档。保留原有配置：864 辆小车、72 辆 AI 公交、玩家铰接公交、标准自动驾驶及公交信号优先。

## 已定位的问题

1. 玩家车在 `(-14920.07, -7210.71)` 永久静止。车头伸过中心线后，车道保护拒绝进入恢复算法；此时前方道路没有障碍。恢复现在允许车身中心仍在己方车道、偏航较小的车辆进行严格改善中心线净空的低速回正，保留完整的障碍与边界检查。
2. 西侧干道的 95、175、176、178 号公交及小车互锁。178 号前车回正时尾部扫向停住的后车，后车又被前车的跟车区挡住。新增路段内后车短距离倒车让位：先验证两节车身的完整倒车轨迹，再验证前车在后车停稳后的前进空间；正常直行排队、乘客服务和后方空间不足均不适用。
3. 第一轮长测第 191 秒，CBD 环岛小车 11547 与 163 号铰接公交互锁，最终触发小车重置。小车被入口车流分离到外侧后，径向回正轨迹穿过公交车头。现在仅在当前半径的前进轨迹能避开公交时，暂缓向内回正；不改变当前位置、不扩大半径，驶过后恢复原目标半径。
4. 远处红灯会把斜停、拖挂未回正的公交楔形阻塞当成正常排队，禁止小车启动已有的安全倒车让位。现在只有朝向对齐且拖挂已摆正的队列享有这项排队豁免。
5. 后续长测中，85、174 号公交在路口前重现尾部互锁。该处仅需约 8 像素的安全退让，但后车方向盘仍大幅偏转，预测在起始处又因 0.1 像素安全余量接触而失败。现在在停车制动时先摆正前轮；允许已经接触的预测余量分离，全程仍拒绝真实车身重叠，新接触保留额外余量。进路口前且车头尚未进入路口的后车也可验证倒退让位。
6. 回正算法调用障碍预测时误把时间传给了行驶距离参数。现按障碍速度乘以预测时长计算位置，并增加远处停放车辆与快速迎面车辆的对照测试。
7. 车头已经在目标车道内、仅需几像素回正来摆正拖挂的公交，仍可能被后方停住的小车要求预留完整并线间距。对这种微量回正，改为核实后车整车处于本车车尾之后，并保留完整行驶扫掠检查，避免在路口里被并线停止线永久卡住。
8. 东南边界路口中，已入弯的小车与右转公交相互占用轨迹时，公交可验证倒退，让已承诺弯道的小车先清空。补齐恢复帧中的目标站和线路上下文，避免恢复结束预转向时空指针；公交已经入弯后，不再把旧的超车车道偏移当成尚未完成的进弯并线。固定夹具覆盖这一连续恢复流程。

## 验证方法

`TestSlot2TrafficSoak` 使用真实 `Game.Update()`，按每秒 60 次推进全部交通。固定随机种子 5，记录每辆公交及小车的位置、停滞、车辆损伤，以及局部重定位和死锁重置。上下客和终点换车停留单独排除；45 秒停滞记为观察，超过至少 90 秒或本路口两个完整信号周期的停滞记为失败。任何重置、局部重定位或新损伤同样使该轮失败，不能用重置车辆作为通过证据。

复现命令（路径改为本机绝对路径）：

```sh
BUS_SLOT2_SAVE=/absolute/path/original-slot2.json \
BUS_SLOT2_OUTPUT=/absolute/path/qualification \
BUS_SLOT2_SECONDS=600 \
go test ./game -run '^TestSlot2TrafficSoak$' -count=1 -v -timeout=15m
```

输出包括 `events.jsonl`、发生异常时的完整现场、`end-state.json`，以及带源存档 SHA-256、模拟时长、车辆数量、最长停滞和各车行驶距离的 `report.json`。十分钟指 36,000 次固定步长的交通仿真，不依赖绘制帧率。

可用 `BUS_SLOT2_TRACE_CARS=11427,5287` 额外记录指定小车的附近路口相位、优先请求队列、位置和速度，用于核对长时间等灯是否得到实际放行。

回归测试包含压线玩家车的连续运动与中心线净空检查、后车倒车的安全边界、环岛小车不碰撞且保留原车道目标，以及约 40 KB 的固定现场夹具，覆盖玩家车、五辆相关公交与邻近小车。

## 测试记录

- 原版基线：玩家车连续 90 秒原地不动，周边多车未恢复。
- 仅修复玩家压线：玩家恢复运营，但西侧公交队列仍互锁。
- 修复后车倒车让位后：原始场景连续 180 秒、零异常记录。
- 第一轮十分钟：发现环岛死锁、红灯队列误判及后续堵点，该轮判定失败，继续修复。
- 后续完整回放发现路口前的紧贴车尾退让问题；修复后的旧故障结束状态继续运行 120 秒，零异常记录。
- 修复预转向后的一轮完整十分钟，异常记录由 30 项降至 3 项，剩余为两项左转小车长等待，以及一项路口内微量回正互锁；继续检查现场。
- 试验过延长宽路口左转绿灯，但全场景回放显示会增加下游红灯队列积压，已撤回该实验，最终保留原信号时序。
- 最终验收：`qualification15` 从原始存档重新开始，完整 600 秒 / 36,000 次更新，**零异常记录，通过**。没有重置恢复计时器，没有改交通密度、车队配置或信号时序。
