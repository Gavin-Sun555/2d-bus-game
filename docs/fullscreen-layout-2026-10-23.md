# Mac 全屏显示适配

原 `Game.Layout` 一直返回固定 1280×720，Mac 屏幕比例不等于 16:9 时，Ebitengine 会保持比例并在上下留黑边。

改为通过 `LayoutF` 按窗口／屏幕实际比例扩展逻辑画布。例如 16:10 屏幕使用 1280×800，超宽屏扩展宽度。界面保持等比缩放，摄像机同步新的画布尺寸，新增区域显示更多地图；不通过拉伸或裁掉界面填满屏幕。浮点尺寸避免 Retina 和缩放显示模式下的比例取整留边。
