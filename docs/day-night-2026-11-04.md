# 游戏时钟、昼夜照明与车辆外观

## 使用

每局地图运行从 08:00:00 开始，默认现实一秒推进游戏一秒，设置中可选择一秒、30 秒或一分钟；06:00–18:00 为白天，其他时间为夜晚。右上角显示精确到秒的时间与状态。05:00–07:00、17:00–19:00 平滑过渡环境亮度。

玩家按 J 或点击右上角按钮开关公交车灯，自动驾驶不会覆盖玩家选择。AI 公交、小车与路灯按昼夜自动启停；制动灯在白天或玩家关闭车灯时仍工作。夜间以柔和光束和道路光池照明，HUD 保持可读。规划视图保留较高可读亮度。

菜单、设置、规划、车库和存档窗口暂停时钟。每个模式的世界分别保存时钟；读档恢复时间、流速与玩家车灯，AI 灯光重新按时间派生。旧存档没有时钟时从 08:00:00 开始。早期已包含时钟的存档保留原有时刻，流速默认一倍。重新开始地图沿用既有重置逻辑，从 08:00:00 开始，保留所选流速。

## 外观

公交增加与物理车身一致的倒角轮廓、明暗边缘、分段窗带、挡风玻璃与雨刷、后视镜、车顶空调、格栅及保险杠；保留双层和铰接结构。铰接尾节不绘制额外驾驶舱。

小车增加轮胎、车身明暗与倒角、车窗、车顶、引擎盖折线、格栅和保险杠，区分轿车、SUV 行李架／车顶玻璃、出租车顶灯。小车缓存区分灯光和制动状态，避免昼夜切换沿用旧图像。

道路路灯是按道路几何派生的渲染设施，避开路口；大小路网和车道宽度变化会刷新位置，不改变交通碰撞几何或消耗模拟随机数。车辆性能、载客量、物理尺寸及车队经济参数不变。
