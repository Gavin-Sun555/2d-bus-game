# 19:05 存档站台停靠卡点修复

当前存档中的铰接玩家车已安全抵达街区 202 东行站前泊位：距停车标记约 3.77 px，横向误差约 0.55 px，车头夹角约 1.13°，车速为零，车况 100%。原程序连续回放 1,200 帧仍停在原位置，未能开门上下客。

局部停靠控制器先规划短距离对正曲线，再判断是否到位。对一辆已经在停靠容差内的长车，这条几像素曲线的切线角变化会触发尾节约束，规划失败后持续输出刹车，挡住了后面的到位判定。上一轮让铰接车保留局部停靠控制后，暴露了这一判定顺序问题。

现在先检查既有的泊位容差、车速、姿态和泊位占用。车辆已经安全到位时直接进入正常开门与停站流程，随后按原有顺序关门、推进目标站、驶离。没有修改车身位置、停靠容差、尾节物理或碰撞扣损规则。
