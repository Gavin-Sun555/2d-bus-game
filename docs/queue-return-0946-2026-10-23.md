## 原因及修改

1. 公交道队首公交偏出路线约 13.7 像素。原来的小幅回正只覆盖相反方向，导致队首等待自己后方队列提供完整超车空隙。现在两个方向的小幅回正均通过完整转向执行器和车身预测低速执行。
2. 玩家处于公交道内侧相邻车道，返回公交道需要一个完整车道的并线。原来没有向后车发布必需并线请求，后方出站公交不断占用间隙。现在接入已有并线让行协商；普通模式也会持续完成这一返回请求。
3. 必需并线的转向约束原本假设目标是内侧直行车道。八车道返回公交道时改用实际道路横向位置计算，避免误把车辆视为靠近中线而过度压低转向幅度。此修正仅适用于公交道左转返回；两车道原有回归逻辑保持原样。
4. 出站后的低速公交车仍可能略有倾斜，且车身占据目标通道，即使中心不在原先狭窄的容差内。后车让行按投影车身、纵向间距及制动距离判断；低速同向后车允许小幅航向偏差。并排车、快速倾斜车辆、对向车和不足制动间距的车辆仍不授予让行。已经停在所离开车道后方、完整车身间距足够的跟车不再要求目标车道的超车缓冲。

诊断信息同时加入必需并线限速、返回公交道限速和并线空隙阻挡，便于区分信号停车与侧后方并线等待。
