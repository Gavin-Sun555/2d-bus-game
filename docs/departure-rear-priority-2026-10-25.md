# 出站后侧小车不再否决进入左转车道

按用户明确的优先级处理：避免长时间卡住优先于为杜绝一次轻微接触而无限等待。上一轮只修复超时恢复计时，没有解决当前公交本可前进却被身后小车拦住的问题，本轮补上直接行驶判定。

## 修改范围

新增 `isDepartureRearCar`：仅在原出发站同一道路的前方 800px 内、至少双向四车道、非路口／环岛、前进且关门的公交上应用。目标须为同向、几乎静止的小车，中心已位于公交后方；另要求它处于动力节后侧，或整个小车已经落在动力节后方。处在动力节正后方但尚未完全退至后方的同车道车辆不使用侧向豁免。

这一分类同时用于普通障碍跟车、方向执行器未来扫掠与铰接车双节未来扫掠，避免一处放行、另一处仍因同一辆后车刹死。道路边界、铰接角限制、信号灯、路口准入及前方车辆约束仍执行。真实接触仍由现有物理系统处理，没有关闭碰撞或传送车辆。

判定不依赖出站曲线的临时长度字段：该字段在曲线结束时归零，若豁免随之消失，车辆刚进入左转车道又会被后方小车卡住。本轮按出发站道路位置限定作用范围，并排除平行街道。
